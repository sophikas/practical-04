# Практична робота №4: Оформлення вебінтерфейсу засобами CSS (Bloom Flowers)

## 1. Опис виконаної роботи
У межах роботи розроблено єдиний зовнішній файл стилів `styles/main.css`, який підключено до всіх сторінок проєкту інтернет-магазину **Bloom Flowers**:
- `index.html` — головна сторінка з навігацією та формою пошуку.
- `login.html` — форма входу в обліковий запис.
- `register.html` — форма реєстрації нового користувача.
- `item-form.html` — форма оформлення індивідуального замовлення букета.

## 2. Основні реалізовані CSS-рішення
- **Design Tokens:** Створено систему змінних у `:root` для кольорів бренду (`--color-primary`, `--color-surface`, `--color-background`), відступів (`--space-*`) та радіусів заокруглення (`--radius-*`).
- **Скидання та блокова модель:** Застосовано `box-sizing: border-box` для всіх елементів та налаштовано базову типографіку без знищення нативних стилів controls.
- **Стани компонентів:** Реалізовано стани `:hover`, `:focus-visible` (із чітким контуром accessibility), `:active` та стилі валідації `:invalid:not(:placeholder-shown)`.
- **Семантична структура:** Стилізовано шапку (`.site-header`), навігацію (`.main-nav`), картки (`.card`), поля форм (`.field-control`) та підвал (`.site-footer`).

## 3. Двоє виправлених CSS-конфліктів за результатами перевірки в DevTools

### Конфлікт 1: Перевизначення кольору активного посилання в навігації
- **Проблема:** Посилання головної сторінки (`.main-nav a.active`) не змінювало свій колір на акцентний рожевий, оскільки загальний селектор `.main-nav a` мав таку ж специфічність і перекривав стилі через порядок оголошення.
- **Діагностика в DevTools:** У вкладці *Styles* правило `color: var(--color-primary)` для `.active` відображалося закресленим.
- **Рішення:** Збільшено специфічність селектора до `.main-nav a.active` та піднято його пріоритет у каскаді `styles/main.css`.

### Конфлікт 2: Зміщення контуру фокусу (Focus Outline) на кнопках та полях
- **Проблема:** При фокусуванні клавіатурою (Tab) контур `outline` накладався безпосередньо на межу кнопки `.button`, роблячи його погано помітним.
- **Діагностика в DevTools:** У режимі перевірки елемента (:focus-visible) помічено відсутність відступу для зовнішнього контуру.
- **Рішення:** Додано властивість `outline-offset: 0.1rem;` та налаштовано напівпрозорий акцентний колір через `color-mix()`.
